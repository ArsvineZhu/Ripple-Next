# Ripple Next 4.2.0

## Highlights

- Settings has a permanent icon rail, an expandable category panel, animated navigation and an independently translucent sidebar. Native window controls and window transitions remain available.
- Arrange bundled, installed and imported fonts in priority order. Each character uses the first matching font, across Settings and the Island.
- Pressed Liquid Glass controls use a clear lens with a thinner refracted track, edge dispersion and a larger handle. The back button follows the pointer while hovered or held.
- Windows/Linux retain their original page-swipe behavior; macOS uses native scroll phases. Centered positioning follows the visible Island throughout size changes. Idle information opens a quick view on hover.
- Music observes native playback changes on Windows/Linux. Artwork, player controls and long titles follow the displayed source. macOS includes its platform-specific media and window behavior.
- AI models have individual parameters, a shared personal instruction and selectable perception channels. The system prompt is built in.
- The in-app guide and product gallery use refreshed 4.2.0 recordings and screenshots.

## Your next action, close at hand

Music is playing. A link needs opening. A copied command is waiting. Ripple Next keeps these everyday actions in one floating desktop Island for Windows, macOS and Linux.

Glance while idle, hover for a quick view, then click to open a full page. Move between pages with horizontal scrolling, arrow keys or Ctrl+1–7. Drafts stay with you when the Island folds.

| Page                   | What you can do                                                  |
| ---------------------- | ---------------------------------------------------------------- |
| Browser Search         | Search or open an HTTP(S) address in your default browser.       |
| Workflows & Quick Apps | Open a group of apps/addresses in order, or launch one favorite. |
| Overview               | See the clock, date, battery and configured weather.             |
| Now Playing            | Choose a player, control playback and activate its window.       |
| AI Assistant           | Use your service/model, stream Markdown answers and copy code.   |
| Clipboard              | Reuse text copied during this session.                           |
| Tasks                  | Keep your next few actions visible and complete them.            |

## Make it yours

Choose page order, visibility, monitor, placement, theme, colors and corners. Settings has an icon rail with expandable category names. Its translucent backdrop is independent of Liquid Glass controls. Press and drag the glass preview to try the lens, deformation and attraction to marked stops.

Build a font chain from bundled choices, installed fonts and imported TTF/OTF/WOFF/WOFF2 files. Put a favorite Latin font first and another family after it for missing glyphs; the same rule works for every writing system. Edit the mixed-script preview to see the combined result.

English, Simplified Chinese, Traditional Chinese and Japanese are included. Simplified Chinese also offers optional Microsoft Chinese and Apple Chinese expressions. The in-app guide contains six real recordings with selectable instructions and user-controlled playback.

## Connect your assistant

Configure Chat Completions, OpenAI Responses or Anthropic Messages with your endpoint, encrypted key and model. Each model keeps its own parameters; one personal instruction and the selected perception channels apply across models. A desktop frame is included only when its channel is enabled and the model supports images. Requests go to your configured service.

## Start using Ripple Next

Install a package or extract a portable ZIP, then launch Ripple Next. Settings opens first. Closing Settings leaves the Island running; use the tray or launch again to reopen it. Ordinary preferences save automatically; credentials use explicit Save/Change.

Preferences, tasks, quick apps and workflows persist locally. Credentials use OS-backed encryption; clipboard history lasts for the current run. Island Liquid Glass is not available yet. The screenshots use isolated demo content, fictional media sessions and a local assistant fixture.
