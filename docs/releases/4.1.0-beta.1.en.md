# Ripple Next 4.1.0-beta.1

**Unreleased.** This beta collects the work in [PR #14](https://github.com/ArsvineZhu/Ripple-Next/pull/14) since the published [4.0.0](4.0.0.en.md). The baseline is `cae1bd522ce38c323175f483f5a4894af109f748`, which is both the `v4.0.0` tag and the PR base. No beta release has been published yet.

## A dedicated settings window

- Settings opens on demand as a regular window, with eight icon-based categories: User guide, General, Appearance & Position, Behavior, Feature pages, Shortcuts & Workflows, Integrations and About. Configuration and workflow/quick-app editing move out of the Island.
- Launching the running app again, the tray and the macOS App menu can reopen Settings. Closing Settings keeps the Island running. Window-role validation separates editor IPC from Island operations; state updates and queued notices reach the appropriate windows.
- OS light/dark colors, plain preference groups and right-aligned closed selectors replace the old form layout. Expanded menus use left-aligned names, leading checkmarks and explanatory text. Conditional rows, category changes, secondary editors, returning and destructive confirmations animate and respect reduced motion.
- Secondary editors provide a glass capsule back button and restore the previous scroll position and focus. Save/Change controls for sensitive fields sit beside their inputs. Numeric fields have consistent sizing and custom steppers. Destructive actions use red text/icons and confirmation; default, visibility and ordering actions retain ordinary colors.
- About starts with the official icon, brand message and version. Developer information, feedback, repository, diagnostics and licenses follow. Brand images and music artwork disable native image dragging.

## Typography, playful Chinese and real workflow recordings

- General → Font uses Alibaba PuHuiTi 3 by default, with System and OpenRunde as alternatives. Samples combine Chinese, Latin and tabular numbers; the selection updates both Island and Settings.
- Original WOFF2 files provide weights 400, 500, 600 and 700, loaded on demand. The full copyright statement is included in third-party licenses. Files are not converted, subsetted or renamed.
- Explicit Simplified Chinese reveals Standard, Microsoft Chinese and Apple Chinese expressions. Original curated overlays retain standard critical actions and technical fields. Dates, numbers and document.lang normalize to zh-CN.
- The guide puts keyboard controls first, then uses actual screenshots and recordings of typography/language, glass, workflow and AI editing. Search, music and weather chapters are removed. Videos include camera motion, playback/pause/seeking, pause offscreen or on exit, and allow only one concurrent playback.
- Body text uses 16px with 1.6 line height, bounded measure, descending heading sizes and selectable explanations.

## Island geometry and positioning

- One geometry hook owns target sizes, radius and native CSS superellipse shape. Still and expanded states use their selected K values, and interrupted or reversed transitions continue from the current geometry. Windows 95 retains square corners.
- Feature identities and layout policies are shared through the page registry. Legacy Settings page references migrate to available feature pages while preserving order and content. Empty workflows use a compact centered layout instead of a large empty frame.
- Appearance keeps a temporary live Island preview. Preset anchors, free-position sliders, background resources, border visibility and inactive hiding remain available. Color fields open the operating system picker, preserve existing alpha and leave cancellation unchanged.

## Experimental Liquid Glass in Settings

The material is the pinned LeonardSEO implementation, combined with rdev interaction. Both MIT notices ship with the app; the original source and A/B/C/D experiment remain available. Island glass is an unavailable internal-testing option.

- Sliders have a 40 CSS pixel well, 3-pixel rounded rail and 32 × 22 resting handle. Switches use a 52 × 26 track and 30 × 20 handle. Pressing immediately reveals a 1.6-times clear lens; release restores white. The thin handle preset keeps track boundaries visible, with blur 0, bezel 4 and thickness 2.5.
- Handles stay still on pointer approach. Held dragging provides bounded directional deformation. Switches change state across the midpoint before release; release does not toggle the result again. Slider values are attracted smoothly toward stops during dragging, with a small sticky centre and continuous escape. Keyboard precision and native pointer capture remain.
- The experimental entry follows position settings. A sticky live preview above the parameters contains real slider, switch, selector and glass button components with local demo values. Disabling Settings glass restores ordinary controls and removes glass-specific pointer response while retaining general transitions.
- Geometry fields and displacement/specular/tint maps are cached independently. Position and CSS transforms do not regenerate textures. Cache limits, DPR updates and bounded menu sizes remain. Time-zone options are memoized and mounted during opening/closing, preventing oversized cold maps; menu highlight motion is continuous.

## Structured AI configuration

Displayed endpoint, key and model numbers follow current list order (1…N) and compact after removal. Stable database IDs and encrypted-key references remain unchanged; selectors, binding summaries and confirmation labels share the same display numbers.

- Multiple named endpoints, encrypted keys and models replace the single endpoint/model fields. Models reference an endpoint and credential, can share a connection, and have a selected default. Stable main-owned IDs, queued partial mutations and atomic credential deletion preserve references across concurrent edits.
- Supported protocols are OpenAI-compatible Chat Completions, OpenAI Responses and Anthropic Messages. Each model can override its system prompt, temperature, reasoning effort, output limit and local context limit.
- Named injection fragments can be enabled, disabled and reordered. Enabled fragments append to the system prompt in order; product metadata and selected-time-zone variables resolve before the request. Context awareness remains disabled.
- Database migrations import the existing AI endpoint/model and opaque encrypted key into the new graph, then retire the old scalar fields. Plaintext keys remain in main-owned secure storage operations.

## Weather, clock and workflow editing

- Weather offers automatic IP location or separate city, region and country fields, with a readable place display and live reading/error preview. It supports the built-in WeatherAPI credential and an encrypted custom key. Main owns retrieval, caching and deduplication.
- The 12-hour clock exposes a conditional Show A.M./P.M. switch. Its localized day period appears on the smaller date line rather than inside the large time digits. Time-zone selection retains keyboard/search behavior.
- Workflows use one target per row with add/remove controls; commas remain part of a target. Names and valid targets form an entry as you edit. Quick-app/workflow lists lead into secondary editors, and long names remain within their containers.

## Native lifecycle, data and distribution

- Development uses a separate profile before the single-instance lock, preventing a local run from changing an installed app's startup settings. Startup no longer probes the OS keychain unnecessarily.
- The Island stays off the taskbar/Dock. On macOS, Settings uses regular activation while open and returns to accessory mode when closed; native Island collection behavior handles Spaces/fullscreen/Mission Control. Windows/Linux keep the tray available.
- Third-party license metadata and Chromium notices ship with the package and can be read in About. Main, preload and renderer contracts and four locale catalogs have been updated together.

## Acceptance and remaining scope

Run `pnpm check`, `pnpm test`, `pnpm package`, then `pnpm start`. Windows native UI acceptance uses isolated Electron and labeled CDP focus/pointer input; it covers guide playback, preview, settings persistence, glass controls, navigation, confirmation and the About hero. macOS/Linux native changes and color dialogs require matching-host acceptance. GPU frame completion and raster/composition memory are not established by rAF or the screenshot tests.

Issue #9's native corner geometry is implemented. Issue #7's larger long-conversation/full-task migration and optional/off-by-default Windows/Linux tray proposal remain outside this beta's completed work. Long conversations and full tasks still live in the Island. Island glass and context awareness remain unavailable.
