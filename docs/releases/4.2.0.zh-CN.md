# Ripple Next 4.2.0

## Highlights

- 设置窗口采用常驻图标栏、可展开分类面板、导航动画和独立半透明侧栏，保留系统窗口按钮与窗口动画。
- 按优先顺序排列内置、系统和导入字体。设置与 Island 中的每个字符，都使用列表里第一个具有对应字形的字体。
- 按住液态玻璃控件时，透镜内的轨道变细，边缘呈现色散，手柄放大。返回按钮仅在悬停或按住时跟随鼠标。
- Windows/Linux 恢复原有翻页手势，macOS 使用原生滚动阶段。Island 改变尺寸时保持居中；空闲时间电量在悬停时进入快览。
- Windows/Linux 原生监听媒体变化，封面、控制按钮和长标题跟随当前播放来源；macOS 保留对应的媒体与窗口适配。
- AI 模型各自保存参数，共享个人指令与可选感知通道，系统提示词内置。
- 应用内指南与产品介绍图库更新为 4.2.0 实际界面的录屏和截图。

## 你的下一步，近在手边

音乐正在播放，链接等着打开，刚复制的命令还在剪贴板里。Ripple Next 将这些日常操作聚在同一个桌面 Island，支持 Windows、macOS 和 Linux。

空闲时瞥一眼，悬停进入快览，点击展开完整页面。横向滚动、方向键或 Ctrl+1–7 切换功能，Island 收起时保留草稿。

| 页面             | 可以做什么                                               |
| ---------------- | -------------------------------------------------------- |
| 浏览器搜索       | 搜索关键词，或在默认浏览器打开 HTTP(S) 地址。            |
| 工作流与快捷应用 | 按顺序打开一组应用和地址，或单独启动常用目标。           |
| 总览             | 查看时间、日期、电量和配置后的天气。                     |
| 正在播放         | 选择播放器、控制播放并唤起对应窗口。                     |
| AI 助手          | 使用自己的服务与模型，阅读流式 Markdown 回答并复制代码。 |
| 剪贴板           | 复用本次运行中复制过的文本。                             |
| 任务             | 记下接下来要做的事，完成后勾选。                         |

## 按你的方式设置

调整页面顺序、可见性、显示器、位置、主题、颜色与圆角。设置窗口的图标栏可展开分类名称，侧栏半透明独立于液态玻璃控件。按住和拖动玻璃预览，体验透镜、形变与刻度吸附。

从内置、系统字体及导入的 TTF、OTF、WOFF、WOFF2 文件组合字体链。把喜欢的英文字体放在前面，再用另一种字体补齐缺失字形；同样的规则适用于任何文字系统。编辑混合文字预览，直接查看组合结果。

支持英文、简体中文、繁体中文和日文；简体中文还可选微软中文或苹果中文趣味表达。应用内指南提供六段实际操作录屏，说明文字可选择，视频由用户控制播放。

## 连接你的助手

配置服务地址、加密密钥与模型，使用 Chat Completions、OpenAI Responses 或 Anthropic Messages。每个模型有自己的参数，所有模型共享一份个人指令和所选感知通道。只有开启桌面画面通道，且模型支持图像时，才会随提问发送一帧桌面。请求发送到你配置的服务。

## 开始使用

安装软件包或解压便携 ZIP 后启动 Ripple Next，首先打开设置窗口。关闭设置后 Island 继续运行，从托盘或再次启动应用即可重新打开设置。普通偏好自动保存，凭据通过“保存／更改”明确提交。

偏好、任务、快捷应用和工作流保存在本地，凭据使用系统安全加密，剪贴板历史保留到本次运行结束。Island 液态玻璃尚未开放。介绍截图采用独立演示数据、虚构媒体来源和本地助手响应。
