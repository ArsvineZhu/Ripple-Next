# Ripple Next 4.1.0-beta.2

## 设置与字体

- 紧凑图标导航与可展开分类面板，支持选中项移动和侧栏平滑收展动画。
- 调整深色配色，使用整合式标题栏和系统窗口按钮。侧栏半透明默认开启，开关位于常规设置最后。
- 按优先顺序组合内置、系统与导入字体，依次补齐缺失字形；导入文件与同家族样式保存在应用配置目录。
- 提供可编辑的混合文字预览、顺序调整和默认字体恢复。Windows 95 主题的默认中文使用内置汉仪像素字体。

## Island 与控件

- 恢复 Windows/Linux 的方向翻页和弹性回位，保留 macOS 的接触阶段与释放判定。
- 修正顶部居中与手动水平定位，适应页面尺寸变化。空闲时间电量入口悬停进入快览。
- 玻璃手柄使用内部压缩采样、边缘折射与色散；返回按钮仅在悬停或按住时跟随，离开后复位。
- 未交互隐藏移至行为页，Island 边框调试开关移至外观与位置页最后。

## macOS 媒体

改善 Island 窗口行为和 Apple Music 封面更新，异步处理封面并将过期结果限制在对应媒体来源。

## 下载

Windows x64：MSI 与便携 ZIP；Linux x64：DEB、RPM 与便携 ZIP；macOS x64/arm64：DMG 与便携 ZIP。参见[使用说明](../../instructions.zh-CN.md)和[平台支持](../platform-compatibility.zh-CN.md)。
