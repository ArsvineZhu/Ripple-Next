# Ripple Next 4.1.0-beta.1

下一步，近在手边。Ripple Next 将音乐、搜索、工作流、AI、剪贴板和任务放进浮动 Island，独立设置窗口负责把它调成你的样子。

## 每种操作，各有位置

- 七个 Island 页面：浏览器搜索、工作流与快捷应用、概览、正在播放、AI 助手、剪贴板、任务。
- 独立设置窗口提供八个分类、二级编辑、自动保存、明确的凭据提交、破坏性操作确认及滚动／焦点恢复。
- 草稿跨导航与折叠保留，键位、原生滚动和减少动态效果偏好保持同一组操作可用。

## 跟得上你的音乐

- Windows 使用 GSMTC 事件，Linux 使用 MPRIS 属性和会话信号，控制直接携带当前播放器身份，不先查询元数据。
- 元数据先显示，本地封面异步加载；会话代次淘汰旧结果，包括快速 A → B → A 和复用临时图片网址。
- idle 保持较短且不预留播放键，悬停快览加宽、显示控制并始终显示歌手；idle 歌手偏好只影响 idle。
- 长文本按实际 DOM 测量，隐藏页面恢复后继续滚动；曲目切换只保留一个当前层。音乐设置可调整 3D 封面、程度和滚动。
- 多播放器使用自动来源与稳定指示器，纵向导航选择；控制和唤起始终针对选中的会话。

## Linux 原生监听

MPRIS／BlueZ 信号、常驻 PipeWire／PulseAudio 流和内置 C inotify 摄像头监听器通过事件更新媒体与设备。监听正常时不定时采样，故障后有界恢复；摄像头热插拔及打开／关闭核对活动持有者，PipeWire 视频采集也计入状态。

## 调成你的样子

选择阿里巴巴普惠体 3、系统字体或 OpenRunde，调整主题、颜色／背景、显示器、位置、圆角、页面顺序和行为。设置液态玻璃提供清晰的按压透镜、节点吸附和实时材质预览。

简体中文提供标准、微软中文和苹果中文。两种趣味表达覆盖指南、设置、空状态和音乐等语境，技术字段、关键操作、错误以及日期和数字保持普通含义。

## 常用工具，一起打开

工作流按顺序启动应用、命令和地址，分别报告目标结果；快捷应用独立启动。AI 支持 OpenAI 兼容 Chat Completions、OpenAI Responses 和 Anthropic Messages、加密凭据、模型提示词／参数、有序注入、流式 Markdown 及代码复制。剪贴板历史在本次运行内有界保存，任务持久化到完成。

指南与产品介绍使用实际英文截图和操作录像，中文表达使用对应语言演示。录像旁的说明可选择，视频由用户控制播放，离开可视区时暂停。

## 软件包与数据

软件包覆盖 Windows x64（MSI／便携 ZIP）、Linux x64（DEB／RPM／便携 ZIP）、macOS x64／arm64（DMG／便携 ZIP）。macOS 使用临时签名。偏好、任务、工作流及加密凭据位于 Ripple Next 用户数据目录；迁移数据前关闭应用并备份数据库。

Island 液态玻璃与 AI 上下文感知尚未开放，Windows／Linux 保持托盘可见。见[使用](../../instructions.zh-CN.md)、[平台支持](../platform-compatibility.zh-CN.md)和[发布验收](../release.zh-CN.md)。
