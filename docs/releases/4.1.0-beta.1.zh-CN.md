# Ripple Next 4.1.0-beta.1

**尚未发布。** 本次 beta 汇总 [PR #14](https://github.com/ArsvineZhu/Ripple-Next/pull/14) 相对已发布 [4.0.0](4.0.0.zh-CN.md) 的改动。基线为 `cae1bd522ce38c323175f483f5a4894af109f748`，同时对应 `v4.0.0` 标签与 PR base。当前完成的是分支准备。

## 独立设置窗口

- 设置按需以普通窗口打开，提供使用指南、常规、外观与位置、行为、功能页、快捷与工作流、集成、关于八个带图标的分类。设置表单及工作流／快捷应用编辑移出 Island。
- 再次启动应用、托盘和 macOS 应用菜单均可打开设置。关闭设置后 Island 继续运行。IPC 按窗口角色校验，状态与排队通知送达相应窗口。
- 设置遵循系统浅色／深色，使用连续偏好分组。未展开的选项右对齐；展开卡片左对齐，带前置勾选和必要说明。条件设置、分类切换、二级页进入／返回及危险操作确认框均有动画，并响应减少动态效果。
- 二级页左上角使用玻璃胶囊返回键，返回时恢复滚动位置和焦点。敏感字段保存／更改按钮紧邻输入框；数字字段统一尺寸并使用定制步进箭头。删除、清空等危险操作使用红色并确认；默认、显示与排序操作保持普通颜色。
- 关于页先展示官方图标、品牌文案与版本，再提供作者、反馈、仓库、诊断和许可。品牌图与音乐封面禁用原生图片拖拽。

## 字体、趣味中文与真实流程指南

- 常规 → 字体提供默认的阿里巴巴普惠体 3、系统字体和 OpenRunde。样张包含中英文及等宽数字；选择同步到 Island 与设置。
- 原始 WOFF2 文件包含 400、500、600、700 四种字重，按需加载，保留完整版权声明并加入应用第三方许可。文件未转换、裁剪或改名。
- 简体中文下新增标准、微软中文和苹果中文表达。趣味文案使用原创覆盖表；核心动作和技术字段继承标准中文。日期、数字及 document.lang 使用标准 zh-CN。
- 使用指南先展示键位，随后用实际截图和录像展示字体／语言、玻璃、工作流与 AI 编辑，不再包含搜索、音乐、天气章节。录像有运镜，提供播放／暂停／跳转，离开可视区或指南即暂停；一次只播放一个视频。
- 正文为 16px、1.6 行高，限制阅读行长，标题按层级缩小，说明可选择复制。

## Island 轮廓与位置

- 统一几何 hook 管理目标尺寸、圆角和原生 CSS 超椭圆。收起与展开采用各自选定的 K，动画中途反向或打断时从当前轮廓继续。Windows 95 保持方角。
- 功能页身份与布局策略进入共享 registry。空工作流采用紧凑居中布局。
- 外观页提供临时 Island 实时预览，保留预设锚点、自由定位、背景资源、边框和未交互隐藏。颜色字段调用系统选取器，保留原透明度，取消时保持原值。

## 设置中的实验性 Liquid Glass

材质沿用锁定的 LeonardSEO 实现，交互组合 rdev 响应。两份 MIT 许可随包分发；原版源码及 A/B/C/D 对照保留。灵动岛玻璃仍为尚未开放的内测选项。

- 滑杆轨道槽高 40 CSS px，圆头轨道粗 3 px，静止手柄为 32 × 22。开关为 52 × 26、手柄为 30 × 20。按下即出现 1.6 倍清晰透镜，松手恢复白色。手柄使用 blur=0、bezel=4、thickness=2.5，保持轨道边界清晰。
- 手柄不受接近吸附影响；按住拖动时提供有界定向形变。开关越过中点即改变状态，松手不会再次反转。滑杆在拖动中平滑吸引节点，中心小范围驻留，继续拖动可离开；键盘微调和原生 pointer capture 保留。
- 实验入口放在位置设置之后。参数上方固定显示真实滑杆、开关、选项与玻璃按钮预览，预览值仅属于本页。关闭设置玻璃恢复普通控件，移除玻璃特有鼠标响应，保留通用过渡。
- 轮廓场、位移、高光与 tint 贴图按依赖分层缓存；纯位置和 CSS transform 不重建贴图。保留缓存上限与 DPR 更新。时区列表先限制尺寸，并在展开／收起时挂载，避免首次生成超大贴图；选项高亮连续移动。

| 默认参数     | 数值               |
| ------------ | ------------------ |
| 折射率       | 2                  |
| 折射强度     | 1.5                |
| 色散         | 0.08               |
| 菜单模糊     | 3 CSS px           |
| 饱和度       | 1.5                |
| 高光倍率     | 1                  |
| 鼠标弹性     | 0.5，上限 1        |
| 节点吸附范围 | 20 CSS px，上限 40 |
| 拖拽形变     | 开启               |

新配置与“恢复默认参数”采用上述数值，已保存的自定义值保持原值。上游 SHA、光学补丁及此前菜单性能基线见[设置玻璃说明](../../src/renderer/components/liquidGlass/README.zh-CN.md)。

## 结构化 AI 配置

接口、密钥与模型的显示编号按当前列表从 1 连续排列，删除后重新连续编号。数据库 ID 与加密密钥引用保持稳定；选择菜单、关联说明和确认文本使用一致的显示编号。

- 单一接口／模型字段改为多接口、命名加密密钥和模型的关联配置。模型引用接口和密钥，可共用连接并选择默认。主进程稳定 ID、排队局部修改及密钥原子删除维持关联一致。
- 支持 OpenAI 兼容 Chat Completions、OpenAI Responses 和 Anthropic Messages。每个模型可调整系统提示词、温度、思考强度、输出上限和本地上下文上限。
- 注入列表支持命名、启用／停用和排序。启用片段按顺序追加到系统提示词，产品与所选时区变量在请求前解析。上下文感知保持未开放。
- 持久化直接使用当前 schema，只写变动的设置或功能列表；删除历史迁移链与版本分发。AI 配置与相关密钥删除保持原子性，读取失败显示启动错误，不覆盖保存的数据。

## 天气、时钟与工作流编辑

- 天气提供 IP 自动定位或城市／省地区／国家三字段输入，使用清晰的位置展示和实时读数／错误预览。支持内置 WeatherAPI 密钥及自行保存的加密密钥；主进程负责请求、缓存和合并重复请求。
- 12 小时制下出现“显示 A.M. / P.M.”，本地化时段显示在较小日期行。时区选择保留搜索与键盘行为。
- 工作流每行一个目标，支持添加／移除，逗号保留在目标内。名称与有效目标形成条目；列表进入二级页编辑，长名称保持在容器内。

## 原生生命周期、数据与分发

- 开发环境在单实例锁之前使用独立配置，避免本地运行改变已安装应用的登录启动等设置；启动不再无必要探测系统钥匙串。
- Island 不进入任务栏／Dock。macOS 在设置打开时采用 regular，关闭后恢复 accessory；原生 Island collection behavior 管理 Spaces、全屏与 Mission Control。Windows／Linux 保留托盘入口。
- 第三方许可清单与 Chromium 许可随安装包分发，可在关于页读取。主进程、preload、renderer 契约及四种语言目录同步更新。

## 验收与剩余范围

运行 `pnpm check`、`pnpm test`、`pnpm package` 与 `pnpm start`。Windows 原生界面使用隔离 Electron，并标注 CDP 焦点／指针输入，覆盖指南播放、预览、参数持久化、玻璃控件、导航、确认与关于页。macOS／Linux 原生改动和选色对话框仍需对应系统验收；rAF 与截图不证明 GPU 整帧完成或光栅化／合成内存表现。

## 全库整改进行中

- 工作流与快捷应用使用同一 LaunchTarget 和批量启动 IPC。原生标识、发现与激活归 Windows／macOS／Linux 适配器，核心启动编排不分支判断平台。
- Windows 按需共享发现请求与五分钟内存缓存，删除提前准备／文件读写以及固定逐项等待。
- 快捷应用编辑器自己管理草稿，显示发现进度并忽略过期查询结果。工作流可添加保存的快捷应用并保留 argv 和工作目录；逐项错误标明目标序号，后续目标继续执行。
- 偏好经同一次提交执行系统效果与保存，返回完成结果，失败恢复已提交视图；删除设置别名、字段转发与 renderer 显示器恢复请求。
- 天气配置使用一份结构化对象和共用刷新 hook，Windows 已核验真实天气／自动定位、手动字段保留及重启。Windows／macOS 登录项要求打包构建并检查系统返回结果。

## 运行路径简化

搜索直接使用原生浏览器桥接。剪贴板历史限制为 100 条不同内容、合计 100 万字符，重复内容移到最前，读取错误在页面显示。媒体类型与选择／能力规则归 shared/media，原生后端选择归 platform/media；选择来源不再读取元数据或等待查询，控制执行后只刷新一次。设备采集查询并行执行。

设置分类使用同一套公共偏好组件，统一字段、操作按钮、二级入口与条件过渡。已删除窗口转发控制器和冗余工作流 hook；分类／功能持有值与编辑操作，公共控件管理渲染与样式。

Island 各页现由公共输入、操作、空状态、反馈及容器组件拼装，并与设置共享基础控件。工作流／快捷应用启动、展开／折叠媒体控制及 Markdown 回答各有复用模块。搜索与任务草稿在切页和折叠后保留，输入法确认不会误提交。Windows 打包运行已通过任务编辑／完成、保留参数及工作目录的原生命令启动、逐项工作流失败、剪贴板读回和真实模型回答／代码复制／重置。

从简约黑或 Windows 95 切回默认时，现提交正式的 default 主题值，修复主题保存被拒绝的问题；Select 的选项值与回调共用类型约束。

诊断改为可读的级别／组件／会话／操作记录，使用正式渲染上报、分窗口上下文、字段校验原因、错误链及原始源码栈；可按运行选择 debug／trace，正常轮询保持安静，正常返回的业务失败也会正确记录。搜索／AI 裸输入聚焦时无框，恢复／添加注入复用圆角按钮，玻璃吸顶预览覆盖滚动区 padding。

Windows 媒体唤起新增 Folia 等已注册自定义桌面 AUMID 的匹配。展开与紧凑音乐视图的错误提示独立显示在原内容下方，不再将封面、歌名和控制按钮上顶。

音乐设置新增默认开启的 3D 封面（原程度）、文字滚动、idle 歌手信息，以及与 Island 同步的播放器选择。Windows 媒体／蓝牙／采集观察改为一个常驻执行器，播放命令不再等待 PowerShell 启动或封面解码。每次封面事件均刷新图片并淘汰旧代次；紧凑悬停保持文字几何位置。[方案与测量验收](../native-observation.zh-CN.md)。

两种音乐卡片的切歌均使用共用模糊／透明过渡，紧凑文字移除基线空隙并垂直居中。
