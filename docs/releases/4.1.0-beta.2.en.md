# Ripple Next 4.1.0-beta.2

## Settings and typography

- Compact icon navigation with an expandable category panel, animated selection and smooth sidebar transitions.
- A darker settings palette, an integrated title bar and native window controls. Sidebar translucency is enabled by default and can be changed at the end of General settings.
- Ordered font lists combining built-in, installed and imported fonts. Missing glyphs continue through the selected fonts; imported files and family styles persist in the app profile.
- Editable mixed-script font preview, priority controls and a default-font reset. Windows 95 uses the bundled HYPixel font for its default Chinese typography.

## Island and controls

- Restore Windows/Linux directional paging and elastic return while retaining the macOS contact-phase and release model.
- Correct centered and manual horizontal positioning, including changing page sizes. Idle time/battery information opens quick view on hover.
- Clear pressed glass handles with compressed interior sampling, edge refraction and color dispersion. Back buttons follow the pointer only while hovered or held and return to rest on exit.
- Move inactive hiding to Behavior and place the Island border debug option at the end of Appearance & Position.

## macOS media

Improve Island window behavior and Apple Music artwork delivery, with asynchronous cover updates and stale-result handling local to each media source.

## Downloads

Windows x64: MSI and portable ZIP. Linux x64: DEB, RPM and portable ZIP. macOS x64/arm64: DMG and portable ZIP. See [usage](../../instructions.md) and [platform support](../platform-compatibility.md).
