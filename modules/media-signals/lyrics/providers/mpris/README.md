# MPRIS text

Implemented: consume an optional `xesam:asText` string already attached to the selected session. Parse timestamped LRC when present; otherwise display untimed text. This does not assume every MPRIS player publishes lyrics, nor infer lyrics from its opaque track ID.

Reference: [MPRIS metadata](https://specifications.freedesktop.org/mpris/latest/Track_List_Interface.html#Mapping:Metadata_Map).
