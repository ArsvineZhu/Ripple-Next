# Folia

Implemented: local `/v1/lyric` fetch and format normalization. Line/word times are seconds; positive offset milliseconds delay display. Native/estimated word timing stays distinct. Restrict this adapter to Folia. Missing title/artist and the absence of a track revision leave association unverified.

Source: [Folia's API contract](https://github.com/chthollyphile/folia-major/blob/009d6e4bd8b40ec618d27552948b6fae05cf0327/docs/lyric-api.md).
