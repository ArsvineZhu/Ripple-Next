# HYPixel 11px U

The Windows 95 Island theme uses `HYPixel11pxU-2.ttf` for Chinese glyphs after W95FA for Latin text. Other themes and the Settings font preference retain their own fonts.

The original TrueType file is bundled unchanged. Its name table identifies HYPixel 11px U, version 9.00.00, and Hanyi Fonts. Copyright and the embedded licensing reference are preserved in [NOTICE.txt](NOTICE.txt) and About → Third-party licenses.
