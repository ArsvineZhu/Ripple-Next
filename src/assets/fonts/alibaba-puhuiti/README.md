# Alibaba PuHuiTi 3.0

The original WOFF2 files are copied unchanged from the user-supplied Alibaba PuHuiTi 3 package. Regular, Medium, SemiBold and Bold have OS/2 weights 400, 500, 600 and 700. Other weights and desktop/EOT formats are not bundled. The application loads these faces only where selected or previewed and uses system fallbacks for missing glyphs.

The text snapshot is retained from the [public statement copy](https://github.com/flyanx/html-poster-to-psd/blob/main/fonts/LICENSE-AlibabaPuHuiTi-3.0.md); its separate project commentary is excluded. No glyph conversion, subsetting or name-table editing is applied.
