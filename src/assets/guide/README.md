# Guide recordings

Captured on 2026-10-25 from the actual Ripple Next 4.2.0 Electron 44.5.1 application on Windows, using an isolated demo profile. Settings uses a 1120 × 780 CSS-pixel viewport. Five clips use English; the Chinese-expression clip uses Microsoft/Apple Chinese.

| Asset           | Actual recorded flow                                                                                                       |
| --------------- | -------------------------------------------------------------------------------------------------------------------------- |
| interface.webm  | Collapse/expand the sidebar and switch through Appearance, Behavior, Pages, Shortcuts, Integrations and General            |
| typography.webm | Open Font, add OpenRunde, move it above Alibaba PuHuiTi, edit a mixed-script preview and restore defaults                  |
| appearance.webm | Open Liquid Glass, press/drag the preview slider and switch, disable/enable Settings glass and return                      |
| workflow.webm   | Create Morning focus, enter two reserved example-domain addresses on separate rows and return to the saved list            |
| expression.webm | Select Simplified Chinese, compare Microsoft/Apple Chinese in About and return to English                                  |
| ai.webm         | Rename a demonstration endpoint, inspect model parameters, edit the shared personal instruction and return to Integrations |

Chromium input drives actual application controls. Captures include a small pointer indicator and native UI transitions. VP9 WebM output is 30 fps without audio; each PNG poster is captured from the same flow after navigation settles. Playback remains user-controlled, one video at a time, with offscreen/hidden/unmount pause.

The disposable profile contains fictional tasks and workflows. Workflow addresses use reserved example domains and are not launched. The demonstration API key is not a service credential; configuration recordings send no model request. The assistant gallery response is generated by a local streaming fixture.

Refresh with the current application and isolated data/cache/lock paths, repeat these actions and inspect the footage before replacing clips and posters. The maintained recorder is [scripts/capture.mjs](../../../scripts/capture.mjs); run pnpm capture as described in the [script guide](../../../scripts/README.md).
