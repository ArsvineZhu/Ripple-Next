# Main process rules

Validate IPC senders and payloads. Preserve Linux ShapeInput-only updates, initial input-region confirmation, and static X11 bundling. Package and run the affected platform after window or adapter changes.

Keep native discovery, activation and platform-specific caches inside platform adapters. Core feature services consume capability interfaces and aggregate domain results; they must not infer native identifiers or manage platform preparation steps.

Keep Windows media and device events behind the shared supervised native executor. Playback commands use the resident executor/cached session and do not wait for artwork decoding. Media observation and fallback sampling belong to main; renderer windows subscribe to the same snapshot and selection. Discard outdated cover generations and keep partial failures local to their session or device.

Keep Linux D-Bus/native-stream reconnection and incremental caches inside their adapters; metadata publishes before generation-guarded artwork. Package native resources for the target architecture.
