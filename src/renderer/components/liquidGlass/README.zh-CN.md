# 设置玻璃控件

`GlassHandle` 使滑杆和开关手柄具有两种状态：静止时为白色胶囊，按住时展开为清晰的 LeonardSEO 玻璃透镜。一个 `useGlassMotion` 控制器观察设置 host，不截获事件；布局锚点与原生值保持稳定，CSS 变量控制相对运动和 1.6 倍展开。提前准备完整透镜采样区域，显示变换与白色层共同过渡，使放大的开关能采样平整绿／灰轨道外的暗色背景。按压、释放和纯位置变化不重新生成贴图。手柄使用 blur=0、默认 saturation=1.2，菜单保留上游模糊默认值。接近参数为 elasticity=0.15、200 CSS px、0.2 秒 ease-out；普通按钮按压仍为 0.96 倍。滑杆不沿取值轴吸附偏移，垂直反馈最多 2 CSS px。失焦、取消、离开和卸载时恢复并释放订阅。

Select 与 SearchableSelect 继续由 Radix/cmdk 管理输入和焦点。收起时数值文字右对齐；展开卡片内，选项名称、必要的说明左对齐，勾选标记位于左侧。卡片以 Radix 定位原点整体缩放，展开 240 ms、收起 140 ms；淡入淡出只作用于前景文字，以保留背景采样。减少动态效果时直接切换。颜色框打开[系统选择器](../../../main/services/colorPicker.ts)。

`PreferenceSwitch` 保留原生 checkbox 语义，轨道为 64 × 30 CSS px，白色手柄为 36 × 24，活动透镜为 57.6 × 38.4。`PreferenceSlider` 保留原生 range，轨道槽高 56 CSS px，静止手柄为 40 × 26，活动透镜为 64 × 41.6。点击轨道和键盘修改以 200 ms 过渡位置，直接拖动立即跟随；节点吸附默认 10 CSS px，并限制在值域的 4%。蓝色进度从零到完整轨道长度。`MenuHighlight` 在 Radix/cmdk 原生选中项之间连续移动，材质与淡入淡出的前景文字为 sibling。颜色框仍使用普通系统选择器入口；60 × 36 CSS px 返回胶囊沿用同一运动控制器。

**外观与位置 → 液态玻璃（实验性）**集中管理启用状态与参数。`GlassPreferencesSchema` 定义有界持久化字段，仅设置窗口提供材质和交互上下文；默认启用设置玻璃。可调整折射率、折射强度、色散、菜单模糊、饱和度、高光倍率、鼠标弹性和节点吸附范围，并恢复默认参数。灵动岛选项固定关闭且不可启用。关闭设置玻璃后移除材质和玻璃鼠标订阅，保留白色手柄、普通菜单／返回键及通用导航和位置过渡。菜单默认 radius=24、bezel=8、K=1.62、specular=0.16、blur=3、ior=1.5、refraction=1、dispersion=0.06、saturation=1.5、光照角度 −135°，厚度为 1.5 × bezel。活动手柄使用清晰场景参数，继续复用同一光学函数、滤镜顺序、遮罩和色散通道。

来源、锁定 SHA、许可证和逐项补丁见 [English](README.md#sources-and-patches)。保留上游原文件、滤镜顺序、三通道色散、高光与 tint 遮罩，只形成一个组合材质实现。二维超椭圆使用欧氏 CSS 像素距离，K=1 退化为原版圆角。贴图分层缓存限制为 96 项／估算 48 MiB，轮廓场缓存为 16 项／24 MiB；纯位置和 CSS 形变不重建资源，不保留持续动画循环。两份 MIT 许可证同时随安装包分发。

SearchableSelect 在 Radix 提供定位变量前限制尺寸；时区列表只在展开／收起期间挂载，选项数据经过 memo。在 i9-12900H Windows 机器、Electron 44.5.1、906 × 604 CSS px、实际 DPR 1.5 下，修复前菜单先撑到 16,461 CSS px 高，每次生成／编码六张贴图，三次展开的主线程长任务为 543／641／593 ms。最终可见窗口的记录中，首次编码三张正确尺寸贴图，共 8.9 ms、长任务 88 ms；重复展开没有编码或长任务。首次冷展开仍超过 16.7 ms 的整帧预算。rAF 间隔只表示调度，GPU 光栅化／合成完成与解码资源内存未测。

A/B/C/D 对照留在 `experiment/liquid-glass-20261013` 的 f095448，本 PR 接入小控件。复测运行 `pnpm check`、`pnpm test`、`pnpm package` 和 `pnpm start`，在外观页检查滑杆完整拖动、键盘微调、菜单展开／收起、提示、焦点恢复、浅色／深色、减少动态效果和窗口尺寸变化。进入编辑页，接近并按压胶囊返回键，移出后释放、失焦，检查归位；切换 12 小时制和自动定位，检查条件设置出现／隐藏动画；进入与返回应按相反方向切换。确认／取消系统选色，并检查已有透明度。

数值回归覆盖 DPR 1／1.5／2 的原版圆角、缓存像素一致性和分层依赖。Windows 实机验证使用 Electron 44.5.1／Chromium 152.0.7977.130、实际 DPR 1.5 和隔离测试配置。macOS／Linux 的调用与返回格式经过 mock 测试，真实对话框需在对应系统复测；依赖见[平台说明](../../../../docs/platform-compatibility.zh-CN.md)。

2026-10-13 的隔离 Electron 验证覆盖原生滑杆拖动／键盘、轨道点击过渡、开关操作、失焦／取消恢复、实验开关和确认框动画。准备资源后，两种手柄的按压／释放新增 Canvas 编码均为零。菜单与高亮测试记录首次六次编码、九次热态选项移动零编码，以及一次 50 ms 长任务。测试在 Windows、实际 DPR 1.5 下使用 CDP 指针与焦点模拟，不据此确认物理鼠标路由或 GPU 整帧完成；前述可见窗口时区记录是独立基准。
