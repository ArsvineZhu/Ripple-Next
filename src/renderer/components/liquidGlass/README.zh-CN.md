# 设置玻璃

开关轨道为 36×16 px，保留 24 px 高的点击区域；滑块手柄为 20×16 px，使用 6 px 强调色轨道，外围无胶囊底色。

滑杆和开关使用白色静止胶囊，按下后立即出现清晰的 1.45× 透镜，采样盒提前按透镜尺寸准备。活动手柄不模糊且无实色填充；位移图压缩透镜内的轨道，并在边缘分离 RGB 采样形成折射与色散，定向高光勾勒轮廓。手柄光学采用共享材质参数派生的紧凑预设。按住拖动形变有界且不偏移位置，松开、取消、失焦和卸载时恢复。

`useGlassMotion` 管理指针响应，不消费宿主事件。手柄在按下时响应，菜单有接近反馈；返回按钮仅在悬停或按住时跟随，离开或在外部释放后复位。原生 range 接管捕获且指针仍按住时保持透镜。减少动态效果保留操作并关闭对应动画。

Select／SearchableSelect 保持 Radix／cmdk 的输入和焦点管理。关闭值靠右，弹出菜单左对齐并提供勾选与描述；定位前限制尺寸，时区列表在展开／收起期间挂载。整体变换使用定位原点，背景采样独立于前景文字透明度。

## 偏好与预览

外观与位置 → 液态玻璃（实验）提供实际滑杆、开关、菜单和按钮的置顶预览。预览值保持局部，材质变化通过公共设置上下文应用；关闭设置玻璃显示普通控件并取消玻璃指针响应。Island 玻璃尚未开放。

重置恢复 IOR 2、折射 1.5、色散 0.08、菜单模糊 3、饱和度 1.5、高光 1、弹性 0.5、吸附半径 20、拖动形变开启。保存值通过普通提交或重置修改。

## 验证

[外观测试](../../../../tests/features/appearance)提供独立数值对照、缓存依赖和指针生命周期验证。对应主机检查原生滑杆拖动／键位、按住开关、菜单／焦点、减少动态效果、调整窗口、编辑返回、预览／重置及原生选色取消。见[平台支持](../../../../docs/platform-compatibility.zh-CN.md)和[素材来源](../../../../docs/assets/screenshots/README.md)。
