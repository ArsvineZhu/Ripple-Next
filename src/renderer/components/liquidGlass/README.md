# Settings glass

`GlassHandle` has a white resting capsule and reveals a 1.6-times larger LeonardSEO lens immediately on press, before dragging. The full sampling box is prepared at its final size so it sees the track and surrounding background. Handles use blur 0, default saturation 1.2, bezel 4 CSS pixels and thickness 2.5 CSS pixels. Their reduced press glow preserves feedback while keeping track boundaries clear. This compact-control preset retains the upstream height profile, refraction, dispersion, masks and filter order. Press, release and position changes do not regenerate maps.

Handles have no pointer approach translation or stretch. The drag-deformation experiment, enabled by default, uses the rdev directional response only while held and moving, with scale bounded to 0.92–1.08 and no position offset. One `useGlassMotion` controller observes the Settings host without consuming events. Buttons and menus retain approach feedback: default elasticity 0.5, range 200 CSS pixels and 0.2 seconds ease-out; buttons retain the 0.96 press scale. Native range thumbs can take over pointer capture during a held drag: capture loss with the button still down does not end the liquid state. Release, cancellation, blur and unmount restore the resting state and release subscriptions.

Select and SearchableSelect retain Radix/cmdk input and focus ownership. Closed values align right. Their glass popup has left-aligned labels, leading checkmarks and optional descriptions. Open/close transitions take 240/140 ms and transform the whole popup about Radix's origin. Only foreground text fades: opacity or filter on an ancestor of the backdrop node would change background sampling. Reduced motion skips both animations. Native color fields open the [system picker](../../../main/services/colorPicker.ts).

`PreferenceSwitch` keeps native checkbox semantics in a 52 × 26 CSS pixel track, with a 30 × 20 white capsule and a 48 × 32 active lens. Dragging across the midpoint changes its checked state while held, in either direction; the release click cannot toggle it again. `PreferenceSlider` keeps native range semantics inside a 40-pixel well with a 3-pixel rail, a 32 × 22 resting handle and a 51.2 × 35.2 active lens. Track clicks and keyboard edits animate the position over 200 ms; direct dragging follows immediately. Stop attraction defaults to 20 CSS pixels (maximum 40), capped at 45% of adjacent-stop spacing to keep fields separate. The progress rail fills from zero to its full length. `MenuHighlight` moves one glass surface continuously between native Radix/cmdk selections; its material is a sibling of the fading text layer. Color fields remain plain system-picker entries, and the 60 × 36 capsule back button uses the same motion controller.

Settings provides **Appearance & Position → Liquid Glass (Exp)**. `GlassPreferencesSchema` owns bounded persisted fields; the Settings-only provider supplies material and motion parameters. Settings glass starts enabled; **Drag deformation (experimental)** starts enabled and resets to enabled with the other parameters. Its editor also controls index of refraction, refraction, dispersion, menu blur, saturation, highlight multiplier, pointer elasticity and stop attraction. The Island toggle is disabled and fixed false. Disabling Settings glass removes the materials and glass pointer subscriptions; white handles, plain menus/back buttons and general navigation/position transitions remain. Default menu optics are radius 24, bezel 8, K=1.62, specular 0.16, blur 3, ior 2, refraction 1.5, dispersion 0.08, saturation 1.5 and light angle −135°. Menu thickness follows 1.5 × bezel.

## Sources and patches

The slider attraction range is measured in CSS pixels and capped at 45% of adjacent-stop spacing. A quintic transition pulls the native input value toward the nearest stop while dragging, with a sticky centre spanning 20% of that radius. Continuing beyond the radius restores continuous movement; the material follows the resulting value. Keyboard fine adjustment bypasses this pointer attraction. The track and blue fill both retain rounded ends.

`vendor/leonard` preserves the unmodified source. Production uses one adapted material. `vendor/adapted/Material.tsx` accepts an external ref, measures offset size, observes DPR and consumes the map cache. The original SVG filter order, three dispersion channels, specular/tint masks and material CSS remain. The motion controller owns press geometry instead of stacking the upstream 1.06 enlargement; the original glow and pressed shadow remain. No rdev material renderer is imported.

`vendor/adapted/maps.ts` adds a CSS superellipse contour, with exponent 2^K, Euclidean CSS-pixel distance and analytic normals. K=1 delegates to the original rounded field. `contour.ts` caches Float64 field samples without folding fractional-DPR symmetry. `maps.ts` caches displacement, specular and tint resources independently: 96 layers / 48 MiB estimated decoded + URL bytes, and 16 fields / 24 MiB. Transforms do not rebuild resources. DPR invalidates its dependent specular resource; refraction strength and tint stay in composition. There is no permanent animation loop or production telemetry.

SearchableSelect bounds its size before Radix supplies positioning variables. The time-zone options are memoized and the command list is mounted only while opening or closing. This prevents an initial 16,461 CSS pixel tall list from generating oversized glass maps. On an i9-12900H Windows machine, Electron 44.5.1, 906 × 604 CSS pixels and native DPR 1.5, the original three opens produced six map encodes each and main-thread long tasks of 543/641/593 ms. In the final visible-window trace, the first open encoded three correctly sized maps in 8.9 ms, with an 88 ms long task; repeat opens had no encodes or long tasks. The first cold open still exceeds a 16.7 ms frame budget. rAF intervals measure scheduling; GPU raster/composition completion and decoded-resource memory were not measured.

The A/B/C/D experiment remains on `experiment/liquid-glass-20261013` at f095448. That branch records the original Siri/Music scenes, source alias checks and comparative measurements. This PR carries only the small control integration. Both licenses are also shipped in `resources/liquid-glass-notices.txt`; upstream vendor files are excluded from formatting, lint, dead-code and duplication reports while remaining type-checked.

## Verification

Run `pnpm check`, `pnpm test` and `pnpm package`, then `pnpm start`. Open Appearance & Position, drag both position sliders end to end, use arrows/Shift+arrow/Home/End, open a menu with Enter and close it with Escape. Check theme descriptions, continuous pointer response, focus recovery, light/dark menus, reduced motion and resizing. Enter an editor, approach and press its capsule back button, release outside, and verify restoration after blur. Toggle 12-hour time and automatic location to check conditional-row animation; entering and leaving an editor should animate in opposite directions. Confirm a native color, cancel another selection and check that alpha is preserved.

The numerical tests retain upstream rounded pixels and compare cached/uncached fields at DPR 1, 1.5 and 2. They also verify independent cache dependencies, rdev response, native-picker cancellation, settings-only IPC, alpha preservation and native range semantics. Windows runtime evidence uses Electron 44.5.1 / Chromium 152.0.7977.130 and native DPR 1.5 with an isolated profile. macOS/Linux picker commands have mocked contract coverage; their actual dialogs require matching-host acceptance. See [platform support](../../../../docs/platform-compatibility.md).

The 2026-10-13 isolated Electron acceptance covers native range dragging/keys, animated track jumps, immediate press lenses, live switch dragging and release-click suppression, capture transfer, blur recovery, the persisted deformation toggle and dialog transitions. The deformation setting survived an unrelated IPC update and a renderer reload. Prepared handle presses and drags produced zero additional canvas encodes. Opening the parameter editor generated three maps for its new geometry. A separate menu/highlight test recorded six cold encodes, zero encodes across nine warm selection moves, and one 50 ms long task. These tests used CDP pointer/focus emulation on Windows at native DPR 1.5; they do not establish physical mouse routing or GPU frame completion. The earlier visible-window time-zone measurements above remain a separate baseline.

The experimental entry follows position settings. Its parameter editor has a sticky live preview of the actual slider, switch, menu and glass button on a fixed grid. Preview values stay local; changing material parameters updates the same Settings glass context. Turning glass off also shows the plain preview. Reset restores ior 2, refraction 1.5, dispersion 0.08, blur 3, saturation 1.5, specular multiplier 1, elasticity 0.5, snap radius 20 and drag deformation on. Elasticity accepts up to 1; attraction accepts up to 40 CSS pixels. Existing saved choices remain until edited or reset.
