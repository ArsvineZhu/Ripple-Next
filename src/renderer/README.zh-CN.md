# Renderer

QuickAppEditor 通过 useQuickApps 自己管理草稿和发现状态；SettingsShortcuts 管理保存的列表与列表编辑。应用发现显示等待提示，过期查询结果不会覆盖新输入。WorkflowEditor 保存共享 LaunchTarget，可添加保留参数与工作目录的快捷应用，网址中的逗号保持原样。WorkflowsTab 一次发送目标数组，显示 main 返回的逐项错误，不再判断目标类型或控制启动间隔。

Renderer 负责 Island 展示、交互和各功能反馈，系统访问通过 [preload 桥接](../preload/README.zh-CN.md)。`Island.tsx` 组合功能视图与 QuickView，`useIslandController` 组合功能 hooks。

Island 直接读取保存的快捷应用，不挂载其编辑器或预先重建发现缓存。排序、隐藏和默认页编辑只由设置管理。启动直接显示内置指南，不再延迟打开浏览器。Bootstrap 失败时先显示本地化错误和诊断文件夹入口，不挂载功能 hooks。

## 状态、语言与样式

独立设置窗口随系统明暗偏好使用中性配色，开启的开关使用绿色，并关闭 Windows 系统强调色边框。普通界面文字不可选中，输入框保留文字选择和复制粘贴。位置选项保留圆形单选指示器，不受窗口超椭圆样式影响。文本输入框最小高度为 36 CSS 像素。

设置默认打开键位优先并使用真实流程录像的使用指南；类别和关键设置行使用现有 Lucide 图标。`SettingsApp` 管理类别过渡与多级编辑历史，只有已提交的视图进入历史，返回恢复滚动与焦点。普通编辑自动保存有效值，API 密钥需手动保存／更改。`AISettings` 管理接口、密钥、模型列表及模型自定义；数字参数使用 148 × 36 CSS 像素输入框和风格化步进按钮。`WorkflowEditor` 每行编辑一个目标。`DangerAction` 管理红色危险按钮及可取消的带进入／退出动画的 HTML alertdialog。条件字段与导航均有动画，减少动态效果时直接切换。关于页先显示产品元信息，再提供可搜索的第三方许可。

Island 导航只包含七个功能页；设置窗口通过应用启动、托盘或菜单打开。页面注册表把 `shared/pages.ts` 中的稳定字符串 ID、尺寸策略与 `lib/tabs.tsx` 中的图标、渲染函数组合起来，供导航、设置与几何动画使用。新增页面通过 `createIslandPageRegistry` 注册。没有可用的配置页面时，导航显示总览。

`AppStateProvider` 加载主进程快照并串行发送类型化补丁；`AppStateProvider` 在各 renderer 同步保存的语言，`SettingsProvider` 编辑共享偏好。`Intl` 按所选语言和时区格式化时间、日期；展开的 12 小时时钟在较小日期行中显示本地化时段。位置编辑使用共享天气配置，包含模式、城市、地区、国家、单位及密钥来源；仅 main 在请求服务时生成查询。自动模式显示主进程返回的位置快照，在进入、聚焦和每分钟刷新。Renderer 不持有天气密钥，也不直接请求天气服务。

`styles/base.css` 负责透明文档、字体和共享动画，`styles/tokens.css` 负责主题／字体 token。Island、通用控件和功能视图各自拥有 CSS Modules。静态展示写入对应模块，动态颜色／几何和 Motion 参数留在所属模块。`OverlayProvider` 将 Select 菜单挂载在 Island 内，`useIslandInteraction` 管理移动、焦点、指针离开与菜单保护。

`useIslandGeometry` 管理实时宽高和圆角过渡。原生 CSS `corner-shape: superellipse()` 在展开时使用 K=1.62，收起时使用 K=1.30。收起半径是当前短边的一半；展开半径使用保存的 0–60 CSS 像素设置（默认 30），并限制在短边的一半以内。宽高与曲率共用一个弹簧进度；切换 Tab 从当前可见几何接续，未完成展开的尺寸差平滑消退。背景、状态边框、阴影与 overflow 裁剪共用 CSS 轮廓。内容容器继承圆角，使用原生 `clip-path: border-box` 几何排除变换后子元素的角落命中，外层阴影保持完整。减少动态效果时直接采用目标几何；不支持 `corner-shape` 的浏览器保留原有圆角，Win95 保持方角。

Select 使用非模态单选菜单；打开时设置仍可滚动，岛内关闭菜单保留展开状态。位置提交保留设置内容与滚动。时钟按分钟边界调度，重新获得焦点／可见性后刷新；电池与设备提醒保留用户已展开的页面。

位置控件使用共用状态中的坐标，键盘调整同样生效。AppStateProvider 串行保存并合并排队中的修改，旧快照不会覆盖最新输入。外观设置持有临时展开预览，离开该页或关闭设置后释放；预览期间位置即时跟随。水平百分比对应可移动距离，两端都保留整个 Island。Win95 的浮雕边框颜色由 CSS 管理，子控件使用直角，其他主题保留原有样式。

滑杆统一使用 `PreferenceSlider`，保留原生 range 的连续取值、键盘微调与 pointer capture。按住拖动时，平滑吸引场使真实值靠近附近刻度，中心有小范围驻留；继续拖动可越过节点。装饰性液态玻璃手柄的中心对应真实值，按下即放大，接近时保持静止。两端含义标识置于同一圆角容器中，蓝色轨道及填充两端均为圆头，在向内收的首尾刻度之外继续延伸，刻度仍对应最小与最大值。圆角和离开延迟允许保存小数，标签不显示数值。材质来源、轮廓、缓存、参数及可选拖拽形变见[设置玻璃控件](components/liquidGlass/README.zh-CN.md)。

`PreferenceSwitch` 使用原生 checkbox 和 switch 语义，支持 Space／Enter、焦点反馈及布尔受控状态。标签说明开启效果，时间格式与温度单位同时说明关闭后的格式。登录启动操作期间禁用对应开关，失败后保留原状态。多选项继续使用 Radix/cmdk，收起文字右对齐，展开名称与说明左对齐，勾选位于左侧；玻璃卡片整体展开／收起，前景淡入与背景采样分开。颜色框使用普通色块与数值按钮，通过仅限设置窗口的 IPC 打开系统选择器。减少动态效果时直接切换。

## 页面导航与滚动

`ElasticScrollArea` 负责原生纵向滚动与稳定内容节点，观察尺寸而不运行永久动画循环。`TabPanels` 负责横向功能页导航，使用连续循环位置、稳定页面标识与不可交互的非当前控件。新请求可调整正在进行的动画目标；模糊与尺寸同步插值，弹性位移以弹簧跟踪输入，并沿平台曲线回弹，目标改变时保留当前位移和速度。 空状态不显示滚动条；其他内容只在实际溢出时显示，内容与视口尺寸变化都会更新该状态。

`wheelGesture.ts` 分类已标准化为 CSS 像素的增量。横向样本容忍 2 像素与 25% 横向位移中较大的纵向漂移；更强的斜向或累计纵向移动将输入交给内容。手势进入纵向后，残余横向样本保持该归属，直到新边界或静默间隔。内嵌横向控件先滚动自身，到边界后再交接。

连续输入最多选择一个循环相邻页，多余距离产生有界弹性位移。原生 ScrollBegin／FlingCancel 分离新手势并合并成对信号；没有原生边界时，使用 150 ms 间隔或持续衰减尾部／重新上升规则识别新手势。键盘重复使用最新状态。

## 媒体归属

`useMedia` 立即读取并每五秒轮询，读取不重叠。控制后刷新，忽略已被操作取代的轮询。读取错误保留旧元数据并禁用控制，操作错误显示在音乐页。能力区分 true、false、unknown：unknown 可尝试，false 或过期状态禁用。

`useMediaPaging` 和 `MediaSessionCarousel` 管理有限的纵向来源页，以自动页或会话 ID 标识。切歌更新内容，保留页面身份。挂载期间会话顺序稳定，新增会话追加、退出会话移除。A 与播放器圆点位于岛内部右侧；单播放器自动模式隐藏指示列，手动模式保留 A 和圆点。

点击、Up／Down／Home／End 与纵向手势可以选择页面。连续手势结合原生边界及共用间隔／尾部规则，最多前进一页；纯横向输入继续功能页导航。非当前卡片不可交互，卡片遵循减少动态效果偏好。

`useMedia` 串行选择，操作进行时保留最新排队目标。等待确认期间禁用控制，命令携带当前会话 ID；失败或会话移除后，以服务快照确定有效选择。

`MediaArtwork` 管理展开页／QuickView 封面的解码失败与悬停状态。失败显示音乐占位图，会话或 URL 改变后重置失败；悬停状态属于该封面组件。

## 启动、剪贴板与反馈

页面定义管理各自的目标尺寸。待办保留原来的 380 × 250 布局，空列表也保留完整空间。工作流为空时使用搜索页尺寸，提示文字横纵居中，使用与搜索框一致的 20px、中等字重；添加工作流后恢复列表尺寸。只有快捷应用时也可在紧凑页面独立启动；完全为空时不保留底栏或分隔线。

`shared/launch.ts` 定义快捷应用和工作流共用的 Application／LaunchTarget，编辑器只解析一次类型。Island 向 main 提交有序目标数组并显示带序号的失败；`lib/search.ts` 处理浏览器查询／模板，直接使用原生 openExternal 桥接。没有 renderer 启动循环或固定等待。

剪贴板通过原生桥接读写文本，每两秒和获得焦点时读取，跳过空值／纯图片。历史在当前运行的内存中保留最多 100 条不同内容、合计 100 万字符；重复内容移到最前，超长文本跳过。读取不重叠，失败显示在已有历史旁。复制按钮管理自身成功／失败。Island 折叠后剪贴板与设备轮询继续运行。

`InlineNotices` 使用已有淡入／模糊过渡，将反馈放在所属功能内。启动错误属于对应应用／工作流行，媒体错误属于音乐页，搜索错误属于 BrowserSearchTab，设置错误属于对应字段。设置范围控件使用主题化轨道、滑块与焦点样式。

`useBackgroundImage` 接受远程 URL 或本地路径，在输入稳定后检查解码，忽略过期结果并安全引用 CSS URL。主进程通过专用协议提供当前配置的本地图片，错误保留在对应设置旁。

见[开发指南](../../docs/development.zh-CN.md)、[平台支持](../../docs/platform-compatibility.zh-CN.md)和[仓库地图](../../INDEX.zh-CN.md)。

关于页先展示官方图标、本地化品牌文案和版本，再放元信息、反馈及许可。品牌图和共用 `MediaArtwork` 封面禁用原生图片拖拽，原有点击操作保持可用。

`SettingsFonts` 使用原生单选与共享 `uiFont`；`AppStateProvider` 将 data-ui-font 应用到各窗口，styles/fonts.css 管理原始 WOFF2 字重。`SettingsGuide` 管理手动播放录像，隐藏／离开可视区即暂停，正文可选择。zh-ms／zh-apple 映射为 i18next 私有语言，Intl 按标准 zh-CN 格式显示。见[录像来源](../assets/guide/README.md)。

默认字体使用阿里巴巴普惠体 3，另可选择系统字体与 OpenRunde。lib/aiDisplay.ts 管理连续显示编号，并直接显示输入名称或回退名称；导航、修改与密钥存储仍使用原有稳定 ID。筛选选项使用完整列表的编号，保证与列表和关联说明一致。
设置消费者直接读取标准 `settings` 并调用 `updateSettings`；hook 只保留需要局部状态的操作。写入在 main 完成系统效果与持久化后返回结果，失败恢复已提交状态。`useWeather` 统一天气与自动地址的刷新生命周期并忽略过期结果；配置对象原样传入 main。

## 可复用偏好组件

`components/preferences` 统一管理分组、卡片、设置行、文本／密码／多行字段、数字字段、按钮、图标操作、二级入口、条件展开及公共样式。分类页提供标签、值和操作，校验与草稿保留在功能内；输入后的操作按钮放在公共字段的 action 插槽。开关、滑杆、选择器、原生取色与玻璃返回键继续使用各自的公共模块。

SettingsTab 只挂载选中的分类或编辑页。常规页管理显示器发现和时区选项，外观页管理背景解码，功能页管理排序／可见性，快捷页管理自己的列表操作；AI 元信息在 AI 视图加载。SettingsApp 管理导航、过渡与滚动／焦点历史，窗口层转发控制器与工作流包装已删除。编辑目标的身份 key 在切换目标时重置草稿。

## 公共内容组件

`components/content` 管理 ActionButton、TextEntry、EmptyState、Feedback 与 Surface。设置偏好字段和操作复用同一输入与按钮基础组件；功能样式只提供布局，公共模块管理字级、颜色、焦点、禁用／按压状态及反馈动画。TextEntry 统一处理回车提交、Shift+Enter 和输入法组合输入。

任务与浏览器搜索自行持有草稿。Island 使用 React Activity，在折叠时保留页面状态并暂停页面副作用；可见页面间切换也保留草稿。AI 和剪贴板 hooks 留在页面生命周期之外，因为 AI 状态控制尺寸及折叠，剪贴板在折叠时继续采集。功能视图直接接收所属 hook 的模型，不再依赖整个 Island 控制器。

LaunchButton 统一管理工作流与快捷应用的等待、防重复触发及逐项失败。MediaControl 统一展开音乐页与 QuickView 的能力检查、当前会话标识、播放图标和焦点／禁用状态。MarkdownContent 管理回答排版、代码容器和原生复制。WeatherIcon、MediaArtwork、ElasticScrollArea 与页面注册表继续管理各自已有契约。
