# Native module rules

Keep native listeners blocking/event-driven while idle, bounded at their transport, supervised by the owning adapter, and cleaned up on application/parent exit. Preserve platform input/window contracts and original third-party notices.

Build on the matching host with pnpm build:native; keep output products ignored. Validate kernel/protocol events and packaged resource paths after listener or build changes. Main adapters own reconciliation, native identity and source-local failures.
